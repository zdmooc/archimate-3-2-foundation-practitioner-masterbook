## Résumé à retenir

```text
ArchiMate 3 Foundation
= connaissance + compréhension du langage

ArchiMate 3 Practitioner
= connaissance + compréhension avancée + application pratique
```

Les deux certifications sont alignées sur **ArchiMate Specification, Version 3.2**.

Il n'existe **pas d'examen ArchiMate 3 Combined Part 1 + Part 2**. Foundation et Practitioner se passent séparément.

## Formats actuels de référence

| Examen | Référence | Format | Durée | Open book | Passage |
|---|---|---:|---:|---|---:|
| ArchiMate 3 Part 1 | OGA-031 | 40 QCM simples | 60 min | Non | 60% = 24/40 |
| ArchiMate 3 Part 2 | OGA-032 | 8 scénarios gradués | 90 min | Oui | 65% = 26/40 |

Pour Part 2 :

```text
meilleure réponse = 5 points
2e meilleure      = 3 points
3e meilleure      = 1 point
distracteur        = 0 point
```

Le livre utilise exactement ce principe pour les scénarios Practitioner et les mocks.
