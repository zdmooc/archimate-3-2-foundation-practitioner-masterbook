## Méthode commune

```text
Need / Concern
→ Motivation
→ Capability
→ Business
→ Application
→ Information / Events
→ Technology
→ Security / Observability / Resilience
→ Baseline / Target
→ Gaps / Work Packages
→ Stakeholder Views
```

Le but est de savoir **réutiliser ArchiMate sur un sujet nouveau**, pas de mémoriser douze diagrammes.
