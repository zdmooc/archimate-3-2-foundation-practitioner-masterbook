# Generated diagrams

Ce dossier reçoit les SVG générés par :

```bash
bash 17-archimate-as-code/scripts/render.sh
```

Les SVG sont des **artefacts dérivés**. Les sources de vérité de cette partie sont les fichiers `.puml` sous `models/`.

En CI, les diagrammes sont publiés comme artefacts GitHub Actions afin d’éviter de versionner inutilement chaque rendu.
